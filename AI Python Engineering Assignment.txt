AI Python Engineering Assignment
Objective
Build a simple Retrieval-Augmented Generation (RAG) application that can answer questions from a set of PDF documents.
We are not evaluating how many frameworks or libraries you use. We are evaluating your ability to read documentation, integrate multiple components, and build a clean, working solution.
________________


Time Limit
Please spend no more than 3 hours on this assignment.
________________


Technology Requirements
Language
* Python 3.11+
LLM
* Use OpenRouter ( https://openrouter.ai/)
* Use free models only
Vector Database
* Use Qdrant (Local Docker or Qdrant Cloud Free Tier) https://qdrant.tech/
AI Tools
You may use any AI coding assistants including Cursor, Claude Code, Codex, ChatGPT, Gemini, etc.
Using AI tools is encouraged.
________________


Problem Statement
You will be provided with one or more PDF documents.
https://drive.google.com/drive/folders/1VN7E4YfANr4Zde4sias_JZw6piyLHvu2?usp=sharing


Your task is to build a Python application that can answer questions using only the information contained in those PDFs.
________________


Functional Requirements
Your application should:
1. Parse all provided PDF documents.
2. Generate embeddings for the document content.
3. Store the embeddings in Qdrant.
4. Retrieve relevant content for a user query.
5. Generate an answer using an OpenRouter free model.
6. Return accurate citations with every answer.
________________


Citation Requirements
Every answer must include:
* Document name
* Page number
* The retrieved text snippet used to generate the answer
Example:
Question:
What is the leave policy?
Answer:
Employees are entitled to 24 annual leave days.
Source:
employee_handbook.pdf
Page 17
Retrieved Text:
"All full-time employees receive 24 days of annual leave..."
________________


Unknown Questions
If the answer cannot be found in the provided documents, your application should clearly respond that the information is not available in the supplied documents.
Do not fabricate answers.
________________
